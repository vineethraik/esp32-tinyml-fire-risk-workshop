# Archived captures

These files document earlier collection stages. The complete workshop does not
use them:

- `dht_export.csv`: early serial schema with unavailable MQ-2/flame columns.
- `dht_session_001.csv`: early DHT-only session.
- `heatgun_box_001.csv`: shorter controlled heat-gun capture.
- `heatgun_box_001_notes.md`: notes for that shorter capture.

Use `../supplied_training_data.csv` for the student workshop.
