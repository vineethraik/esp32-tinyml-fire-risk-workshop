TinyML browser lessons

Training for these lessons runs in the browser. Every name in the top navigation opens its page.

Install tools — VS Code, PlatformIO, Git, CP210x. New tab. Not part of the lesson path.

  1. Perceptron — edit examples, pick an activation, and step through weight changes.
  2. Neural net — add hidden layers, set each size, and step through the average weight change.
  3. Data — slide a ten-reading window, build the 20-feature vector, label early/late, and save early labels for Train.
  4. Train — train 20→12→3 on teaching windows or your early Data labels; read accuracy plus the confusion matrix.
  5. Run — connect the ESP32 over Web Serial and send AT commands from buttons.
