TinyML browser lessons

Training for these lessons runs in the browser. Every name in the top navigation opens its page. Train and Run are placeholders until those lessons are built.

  1. Perceptron — edit examples, pick an activation, and step through weight changes.
  2. Neural net — add hidden layers, set each size, and step through the average weight change.
  3. Data — slide a ten-reading window, build the 20-feature vector, label it, and see the time split.
  4. Train — the thermal-risk network and both scores. Next lesson.
  5. Run — copy the weights into the ESP32 header. Next lesson.
