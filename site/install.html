Install

PC tools for the workshop board. Git, VS Code, the PlatformIO IDE extension, and the CP210x USB driver. Windows, Linux, and macOS. This page is not part of the browser neuron lessons.

1. Git

Download the installer from git-scm.com/download/win. Run it. Leave the default editor if unsure.

Verify in Command Prompt or PowerShell: git --version

2. VS Code

Download the Windows installer from code.visualstudio.com/download. Install. Tick “Add to PATH” if the installer offers it.

Verify: open Visual Studio Code from the Start menu.

3. PlatformIO IDE extension

In VS Code: Extensions. Search PlatformIO IDE (platformio.platformio-ide). Install. Reload when asked. The first PlatformIO run may download the toolchain; that needs internet.

Verify: the PlatformIO alien icon appears in the VS Code sidebar.

4. CP210x USB driver

If the board is not detected, download Silicon Labs CP210x_Windows_Drivers.zip. Unzip it. Run the installer inside. Plug the board in with a data USB cable.

Verify: Device Manager → Ports (COM & LPT). A COM port should appear (name may differ).

1. Git

Debian/Ubuntu: sudo apt update then sudo apt install git. Fedora: sudo dnf install git.

Verify: git --version

2. VS Code

Download the .deb or .rpm from code.visualstudio.com/download and install with the distro package tool.

Verify: open VS Code, or run code --version.

3. PlatformIO IDE extension

In VS Code: Extensions. Search PlatformIO IDE (platformio.platformio-ide). Install. Reload when asked. The first PlatformIO run may download the toolchain; that needs internet.

Verify: the PlatformIO alien icon appears in the VS Code sidebar.

4. CP210x USB access

The Linux kernel often already includes cp210x. Add your user to the serial group, then log out and in. Debian/Ubuntu: sudo usermod -aG dialout $USER. Arch: use group uucp. Plug the board in with a data USB cable.

Verify: ls /dev/ttyUSB0 (name may differ; also try /dev/ttyACM0).

1. Git

In Terminal: xcode-select --install. Or download from git-scm.com/download/mac.

Verify: git --version

2. VS Code

Download the macOS build from code.visualstudio.com/download. Drag it to Applications.

Verify: open Visual Studio Code from Applications.

3. PlatformIO IDE extension

In VS Code: Extensions. Search PlatformIO IDE (platformio.platformio-ide). Install. Reload when asked. The first PlatformIO run may download the toolchain; that needs internet.

Verify: the PlatformIO alien icon appears in the VS Code sidebar.

4. CP210x USB driver

If the board is not detected, install Silicon Labs CP210x VCP drivers. If macOS blocks the kext, allow it in System Settings → Privacy & Security. Plug the board in with a data USB cable.

Verify: ls /dev/cu.SLAB_USBtoUART /dev/cu.usbserial-* (name may differ).

If the Silicon Labs driver does not create a port, the board may use a CH340 chip instead of CP210x. Check the chip marking on the USB-UART part of the board.
